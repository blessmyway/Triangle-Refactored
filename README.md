# Зауваження до коду (Code Review)

1. **Дивні назви геттерів і сеттерів:** Замість стандартних `getA()` / `setA()` використовуються `takeA()` і `putA()`. У Java так писати не прийнято, краще дотримуватися зальноприйнятого суфікса get/set.
2. **Немає перевірки на від'ємні значення:** У сеттери можна передати `0` або від'ємні числа, і клас це спокійно проковтне.
3. **Можна створити неіснуючий трикутник:** Взагалі відсутня перевірка правило нерівності трикутника ($a + b > c$). Зараз можна задати сторони `1, 2, 10`, що фізично неможливо.
4. **Немає обробки помилок:** Якщо дані некоректні, програма ніяк про це не сигналізує і не викидає `IllegalArgumentException`.
5. **Порожній конструктор:** Немає нормального конструктора з параметрами для зручної ініціалізації об'єкта одразу при створенні.
6. **Не реалізовані базові методи:** Відсутні `equals()`, `hashCode()` та `toString()`, через що трикутники не можна нормально порівнювати між собою або виводити в консоль для дебагу.
7. **Відсутній Javadoc:** Немає опису методів та класу.
